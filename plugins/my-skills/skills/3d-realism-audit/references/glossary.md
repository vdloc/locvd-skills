# Glossary — book-derived rendering terms

RTR3 = *Real-Time Rendering* 3rd ed.; PBRT3 = *Physically Based Rendering* 3rd ed.
`refNN` = file in this folder.

**Adaptation (light)** — temporal smoothing of exposure toward current log-average luminance (RTR3 §10.11; ref07)
**Aerial perspective** — color/intensity shift with distance from atmospheric scattering; fog is its crude stand-in (RTR3 §10.15; ref07)
**Aliasing** — high frequencies reappearing as low-frequency error from undersampling (RTR3 §5.6; PBRT3 §7.1; ref06)
**Alpha to coverage** — alpha converted to MSAA sample coverage; order-free cutout edges (RTR3 §5.7, §6.6; ref03, ref06)
**Ambient occlusion k_A** — cosine-weighted fraction of unoccluded hemisphere; scales indirect light only (RTR3 §9.2; ref05)
**Anisotropic filtering** — multiple mip probes along a pixel footprint's long axis (RTR3 §6.2.2; ref03)
**Bent normal** — cosine-weighted average unoccluded direction; indexes irradiance map (RTR3 §9.2.2; ref05)
**Bloom** — bright-pass, blurred, additively composited glow signaling overexposure (RTR3 §10.12; ref07)
**BRDF** — ratio of outgoing radiance to incoming irradiance per direction pair; units sr⁻¹ (RTR3 §7.5.1; ref02)
**Cascaded shadow maps (CSM/PSSM)** — per-depth-slice shadow maps, each ~2–3× deeper than the previous (RTR3 §9.1.4; ref05)
**Color temperature** — blackbody temperature matching a light's spectrum; tungsten ~2700 K, D65 ~6504 K (PBRT3 §12.1; ref04)
**Conductor / dielectric** — complex vs real index of refraction; metals have no body reflectance (PBRT3 §8.2.1; ref02)
**Depth complexity / overdraw** — surfaces per pixel / pixels shaded more than once (RTR3 §15.4.5; ref08)
**Detail texture** — high-frequency overlay combating magnification blur (RTR3 §6.2.1; ref03)
**Directional-hemispherical reflectance R(l)** — total reflected fraction for one incoming direction; must be ≤ 1 (RTR3 §7.5.1; ref02)
**Encoding gamma** — scene-linear → stored value transfer; sRGB ≈ 0.45 (RTR3 §5.8; ref01)
**Environment map** — directional HDR radiance table assuming distant surroundings (RTR3 §8.4; ref04)
**Exponential fog** — f = e^(−dz); the Beer–Lambert-justified form (RTR3 §10.15; ref07)
**F0 / RF(0°)** — Fresnel reflectance at normal incidence; the characteristic specular color (RTR3 §7.5.3; ref02)
**Fill / key / rim light** — cinematic lighting roles; fill has no specular (RTR3 §8.6.2; ref04)
**Fresnel effect** — reflectance rising to 1 at grazing angles (RTR3 §7.5.3; ref02)
**Geometry / visibility term** — shadowing-masking G over cosθi·cosθo in microfacet BRDFs (RTR3 §7.6; PBRT3 §8.4.3; ref02)
**Hemisphere light** — two-color sky/ground irradiance lerped by (1+cosθ)/2 (RTR3 §8.6.3; ref04)
**Hysteresis (LOD)** — separate switch thresholds up vs down to prevent flicker (RTR3 §14.7.2; ref08)
**Irradiance** — incident power per area (W/m²); lux photometrically (RTR3 §7.1; PBRT3 §5.4; ref01)
**Irradiance environment map** — cosine-convolved env map indexed by normal (RTR3 §8.6; ref04)
**Key value a** — tone-mapping target mid-grey; normal 0.18 (RTR3 §10.11; ref07)
**Log-average luminance** — geometric-mean scene luminance for exposure (RTR3 eq. 10.8; ref07)
**Luminance Y** — 0.2127R + 0.7152G + 0.0722B on linear sRGB (RTR3 eq. 7.11; ref01)
**Meso / micro scale** — normal-map-scale vs sub-pixel BRDF-scale detail (RTR3 §6.7, §7.8.1; ref03)
**Microfacet theory** — surface as tiny mirrors with an NDF; f = D·G·F / (4 cosθi cosθo) (RTR3 §7.5.6; PBRT3 §8.4.4; ref02)
**Mipmap** — prefiltered image pyramid for minification (RTR3 §6.2.2; PBRT3 §10.4.3; ref03)
**MSAA** — per-sample coverage/depth with one shade per fragment (RTR3 §5.6.2; ref06)
**NDF D(h)** — distribution of microfacet normals; controls highlight shape and roughness (RTR3 §7.5.6; ref02)
**Normalization (BRDF)** — scaling a lobe so its color parameter equals reflectance (RTR3 §7.6; ref02)
**Nyquist limit** — half the sampling rate; frequencies above alias (RTR3 §5.6.1; ref06)
**Obscurance** — AO variant with distance falloff to d_max (RTR3 §9.2.3; ref05)
**Oren–Nayar** — rough-diffuse microfacet model; σ ≈ 0.52 rad very rough (RTR3 eq. 7.57; PBRT3 §8.4.1; ref02)
**Over operator** — c_o = αc_s + (1−α)c_d; order-dependent blend (RTR3 §5.7; ref06)
**PCF** — filtering of shadow comparison results (RTR3 §9.1.4; ref05)
**PCSS** — PCF with blocker-distance-driven kernel width; contact hardening (RTR3 eq. 9.9; ref05)
**Peter-Panning** — shadow detached by excessive bias (RTR3 §9.1.4; ref05)
**Perspective / projective aliasing** — magnified / stretched shadow texels (RTR3 §9.1.4; ref05)
**Planar reflection** — reflected camera through a plane, clipped and stenciled (RTR3 §9.3.1; ref04, ref05)
**Premultiplied alpha** — RGB stored multiplied by α; required for correct filtering (RTR3 §5.7; ref06)
**Prefiltered reflection map** — env map convolved per roughness level in mips (RTR3 §8.5; ref04)
**Radiance** — power per projected area per solid angle; distance-invariant (RTR3 §7.1; PBRT3 §5.4; ref01)
**Radial fog** — fog from Euclidean eye distance, rotation-invariant (RTR3 §10.15; ref07)
**Scattering albedo ρ** — fraction of entering light that re-emerges; diffuse color; concrete/soil 0.15–0.4 (RTR3 §7.5.4; ref02)
**Schlick approximation** — F ≈ F0 + (1−F0)(1−cosθ)⁵ (RTR3 eq. 7.33; PBRT3 §8.5; ref02)
**Second-depth shadow map** — back faces only in shadow map; leaks at contacts (RTR3 §9.1.4; ref05)
**Shadow acne** — false self-shadowing from depth sampling (RTR3 §9.1.4; ref05)
**Slope-scaled bias** — shadow bias increasing with surface tilt from light (RTR3 §9.1.4; ref05)
**Small-batch problem** — per-draw-call CPU overhead dominating; X = B·C·U/F batches/frame (RTR3 §15.4.2; ref08)
**Smith G1 / Λ** — masking function G1 = 1/(1+Λ); height-correlated G = 1/(1+Λo+Λi) (PBRT3 §8.4.3; ref02)
**Spherical harmonics (SH9)** — 9 RGB coefficients represent irradiance to ~1% (RTR3 §8.6.1; ref04)
**SSAO** — screen-space depth-sampled AO, rotated kernel + depth-aware blur (RTR3 §9.2.5; ref05)
**Supersampling** — shading every sub-sample (RTR3 §5.6.2; ref06)
**Tangent space / handedness** — per-vertex TBN frame; mirrored UVs need a sign bit (RTR3 §6.7; ref03)
**Toksvig factor** — gloss reduction from averaged-normal length in mips (RTR3 eq. 7.62; ref03)
**Tone mapping** — HDR luminance → display range, after blending, before encode (RTR3 §10.11; ref07)
**Trowbridge–Reitz (GGX)** — long-tailed NDF matching real surfaces (PBRT3 §8.4.2; ref02)
**Variance shadow map** — filterable depth moments; light bleeding with stacked occluders (RTR3 §9.1.4; ref05)
**Vector irradiance** — summed radiance vectors; makes Lambert area lights exact point lights (RTR3 §8.2; ref04)
**Wrap lighting** — (cosθ + c)/(1 + c) diffuse for area/subsurface look (RTR3 eq. 8.16; ref04)
